title: Lateral Flow Assay Strip CAD Library
description:  short description of the project
skills: Developed a standardized SolidWorks library of lateral flow assay strip holders based on commonly used strip dimensions 
and configurations. The library was created to streamline the development of custom assay reader components by providing reusable, 
validated starting geometries rather than requiring existing client models to be modified for each new application.


Designed the models with standardization and adaptability in mind, allowing common configurations to be quickly incorporated into new 
designs while still supporting client-specific requirements. This reduced repetitive CAD work, improved consistency across projects, and 
created a more efficient workflow for developing custom hardware solutions.


- SolidWorks
- Mechanical Design
- CAD Standardization
- Parametric Modeling
- Design for Manufacturing (DFM)
- Product Configuration
- Engineering Documentation
