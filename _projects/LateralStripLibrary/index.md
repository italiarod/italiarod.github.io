## Standardized CAD Library

Custom lateral flow assay products frequently required adapting existing hardware to accommodate different strip dimensions. Previously, developing a new configuration could involve locating a similar client design and modifying its geometry, creating additional CAD work and making it more difficult to maintain consistency between projects.

To streamline this process, I developed a standardized SolidWorks library of lateral flow assay strip holders based on commonly encountered strip dimensions and configurations. Rather than designing around the requirements of a single client, the models were created as reusable starting points that could be incorporated into future custom products.

I organized the library around standardized dimensions and consistent design conventions so that engineers could quickly identify an appropriate starting geometry and modify it when necessary for client-specific requirements. This reduced reliance on previous client models while creating a more systematic approach to developing new configurations.

The project shifted a repetitive design task into a reusable engineering resource, reducing unnecessary CAD work and improving consistency across future product development.

## Library Reference Guide

To make the CAD library easier to navigate and use, I created an accompanying reference document that serves as a visual guide to the available models. The document allows users to review the standardized configurations and their relevant dimensions without having to individually open and inspect multiple SolidWorks files.

Each entry was documented so that an engineer could compare the available options, identify the model that most closely matched a new project's requirements, and locate the corresponding CAD file within the library. This created a connection between the visual reference material and the underlying SolidWorks models.

The guide was designed with future expansion in mind, allowing additional configurations to be documented as the library grows. By pairing standardized CAD models with accessible technical documentation, the project created a more efficient and repeatable workflow for selecting, reusing, and adapting existing designs for new lateral flow assay applications.
